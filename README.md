# 🐾 Pet-Adoption-Chatbot

An intelligent chatbot developed using **Botpress** to streamline the pet adoption process. It features personalized pet recommendations, an easy pre-adoption application process, expert pet care advice, and guidance to support new pet owners post-adoption.

---

## 🚀 How to Use

1. **Download** the `Pawsitive Match.bpz` file and open it in **Botpress Studio**.
2. Click **"Publish"**, copy the shareable link, and paste it into a new browser tab to launch the chatbot.
3. **Start the conversation** by typing any message. The chatbot will prompt you to:
   - Begin a personalized match by selecting preferences, or  
   - Enter the name of a pet featured on the shelter's social media.
4. The chatbot will recommend the most suitable pet based on your selected traits. If there’s a match, you’ll be prompted to complete a pre-adoption form.
5. You can also ask questions about pet care and receive helpful tips and ongoing guidance.

---

## 🌟 Key Features

- **🎯 Personalized Pet Matching**  
  Recommends ideal pets based on user preferences.

- **📄 Pre-Adoption Application**  
  Simplifies the adoption process with a built-in application form.

- **📚 Pet Care Guidance**  
  Provides expert advice to help new pet owners prepare and care for their pets.

- **⏰ 24/7 Accessibility**  
  Always available to assist users anytime, anywhere.

## 🧠 Technologies Used

- **Botpress Studio** – For flow design and chatbot development  
- **Flow Editor** – Multi-step flows, decision nodes, and conditional logic  
- **Knowledge Base** – Dynamic responses to common user queries  
- **Slot Filling & Entity Extraction** – Captures structured user input  
- **Actions & Hooks** – Implements custom logic  
- **Input Validation** – Ensures accurate user responses
